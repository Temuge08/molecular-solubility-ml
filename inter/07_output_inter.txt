These results are enough to make a model-selection decision.

The main conclusion is:

Choose the descriptor-only Random Forest as our final RF model.

Even though the combined model had a trivially lower RMSE during tuning, the molecule-level analysis shows no meaningful advantage from adding the 2,048 Morgan bits.









What did the applicability-domain analysis show?

This part is also interesting.
You hypothesized:
more similar to training data
        ↓
smaller prediction error

But:
Descriptors:
rho = -0.037
p = 0.698

Combined:
rho = -0.084
p = 0.383

Essentially:
rho ≈ 0

So nearest-neighbor Tanimoto similarity did not meaningfully correlate with validation error.
We should report that honestly rather than forcing an applicability-domain story.
The bins also don't show a clean monotonic trend:

Similarity       Descriptor MAE
<0.30                0.618
0.30-0.39            0.556
0.40-0.49            0.767
0.50-0.59            0.431

The 0.40–0.49 group actually performs worse than less-similar groups.

However, note that some upper bins have very few molecules:

0.60–0.69     n=2
0.70–0.79     n=1

so we shouldn't interpret those strongly.
A reasonable conclusion is:

Within this cluster-split ESOL validation set, maximum Morgan-Tanimoto similarity to the training set was not a reliable standalone indicator of prediction error.
That's a useful negative result.








Why might similarity not correlate with error?

Remember what model won:

RDKit physicochemical descriptors

not Morgan fingerprints.

Our descriptor model is learning relationships involving:

LogP
MW
TPSA
HBD
HBA
rotatable bonds
rings
...

A validation molecule may have low Morgan similarity to training structures but nevertheless have familiar physicochemical properties:

structurally unusual
       ↓
Tanimoto = 0.25

but:

MW = 190
LogP = 2.1
TPSA = 45
HBD = 1
HBA = 3

       ↓
well represented descriptor space

So molecular fingerprint similarity and descriptor-space familiarity aren't the same thing.

That's actually a nice finding from this experiment.

Later, we could construct an applicability domain using descriptor-space distance instead:

standardized descriptors
        ↓
distance to training molecules

But it isn't necessary before finishing version 1.
